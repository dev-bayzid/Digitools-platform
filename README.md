# 🚀 DigiTools

A modern and responsive digital tools marketplace built with **React.js**, **Tailwind CSS**, and **DaisyUI**. DigiTools allows users to browse premium digital products, add them to a shopping cart, manage selected items, and complete a simple checkout experience with real-time notifications.

---

## 🌐 Live Demo

🔗 **Live Site:** https://digi-tools-online.netlify.app/
## 📂 GitHub Repository

🔗 **Repository:** https://github.com/dev-bayzid/Digitools-platform
---

# ✨ Features

- 🛒 Dynamic shopping cart with live cart count
- 📦 Product data loaded from JSON
- 🔄 Toggle between Products and Cart
- 💰 Automatic total price calculation
- ❌ Remove individual products from the cart
- ✅ Proceed to Checkout clears the entire cart
- 🔔 Beautiful toast notifications using React Toastify
- 📱 Fully responsive across desktop, tablet, and mobile devices
